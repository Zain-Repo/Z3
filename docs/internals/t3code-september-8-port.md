## Validation and surfaces

- All 98 focused tests passed across seven files, covering minimap resolution/rendering, terminal shortcuts, file-drop event handling and queue isolation, session idle boundaries, and native context menu ownership.
- Web, desktop, and server package typechecks passed. Desktop/server reported existing Effect suggestions outside this change. Targeted lint and `git diff --check` passed. Unrelated composer formatting was retained to keep the diff focused.
- Web and desktop share the coding UI changes. The session reaper applies to every provider through the common service. No wire contracts changed.

- Browser, live Electron, real clipboard, and relay/tunnel interaction checks were not run; repository instructions require explicit authorization for computer use. No development servers or real provider sessions were started.
