# Z3Chat Library

Open **Library** in the Z3Chat sidebar to browse your uploaded files and images, newest first. Z3Chat is available in the desktop app.

- Search by filename, or filter to images or documents and other files.
- Switch between thumbnail and list views.
- Select a file to preview an image, download the original, or open its conversation.
- Use **Next** and **Previous** to browse older uploads. **Refresh library** checks for new uploads.
- If you have multiple environments, choose an environment from the menu at the top of the page. Each environment keeps its own library.

Drag files onto the upload area or select **Choose files** to add them directly to Library. You can upload up to ten files at a time: images up to 10 MB each, and other files up to 2 MB each. Keep the page open until the uploads finish.

Each file shows its reading, uploading, and saved state. The progress bar counts files saved successfully. Failed uploads show a **Retry** action; retrying an upload does not create another copy. Choose a smaller file if it exceeds the size limit.

Direct uploads are independent of conversations. Select one and use the remove button to delete the uploaded copy after confirmation. The original on your device is unchanged.

The library also includes uploads from archived conversations. Conversation uploads follow your history: deleting a conversation removes its files from this view. Files uploaded only as project sources, unsent attachments, and ZImage generations are not included. Generated images remain in ZImage.

Connect to the environment that holds a file to preview or download it. An older server may need to be updated before it supports Library.
