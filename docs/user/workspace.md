# Your Z3 workspace

Use the workspace controls at the top of the sidebar to switch between **Code** and **Image**. The desktop app also includes **Chat**. Your selected workspace is remembered on this device.

**Commands** in the sidebar opens the command palette. It also displays your configured keyboard shortcut. Use the palette to find threads, add projects, and access workspace actions.

In **Chat** and **Code**, choose another model or provider from the composer before sending your next prompt. The conversation stays in the same thread. Wait for the current turn to finish, or stop it, before changing providers. You can switch back later.

When a different provider needs a fresh session, Z3 passes recent conversation text to it and records the switch in the timeline. Long histories may be shortened to fit the request limit. Previous attachment contents and the old provider's internal tool state are not replayed; reattach files if the new model needs them. Model changes within a provider still follow that provider's supported switching behavior.

On web and desktop, drag an image onto a coding thread in the sidebar to open that thread and attach the image to its composer. Review it before sending: dropping an image never sends a message. The usual attachment limits apply. Coding threads currently accept image attachments; other file types show an unsupported-file message.

In a conversation with multiple turns, hover over the timeline minimap or focus it with the keyboard to reveal **Previous turn** and **Next turn**. These controls step from the first visible turn and disable at the beginning or end of the conversation. The minimap is available with a mouse or trackpad.

In the desktop browser panel, right-click to access native editing actions, copy links or images, and choose spelling corrections. These actions also work in browser sign-in popups.

In a new coding thread, choose **Plan a change**, **Investigate a bug**, or **Review changes** to add a prompt starter. The text is appended to your draft. Edit it before sending; selecting a starter does not run an agent or change your files.

If you have no projects yet, choose **Open a project** to select a folder on a connected environment, or **Connect an environment** to work on another machine. Once you have a project, Z3 opens directly into a new draft as usual.

Choose **Personalize workspace** to open appearance settings. The default **Z3 · Graphite** palette pairs graphite surfaces with copper accents and supports light, dark, and system appearance. Other palettes remain available, including **Rose**, **Grove**, **Ocean**, **Ember**, and **Iris**.
