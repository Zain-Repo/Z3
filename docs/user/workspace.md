# Your Z3 workspace

Use the workspace controls at the top of the sidebar to switch between **Code** and **Image**. The desktop app also includes **Chat**. Your selected workspace is remembered on this device.

**Commands** in the sidebar opens the command palette. It also displays your configured keyboard shortcut. Use the palette to find threads, add projects, and access workspace actions.

In a new coding thread, choose **Plan a change**, **Investigate a bug**, or **Review changes** to add a prompt starter. The text is appended to your draft. Edit it before sending; selecting a starter does not run an agent or change your files.

If you have no projects yet, choose **Open a project** to select a folder on a connected environment, or **Connect an environment** to work on another machine. Once you have a project, Z3 opens directly into a new draft as usual.

Choose **Personalize workspace** to open appearance settings. The default **Z3 · Graphite** palette pairs graphite surfaces with copper accents and supports light, dark, and system appearance. Other palettes remain available, including **Rose**, **Grove**, **Ocean**, **Ember**, and **Iris**.
